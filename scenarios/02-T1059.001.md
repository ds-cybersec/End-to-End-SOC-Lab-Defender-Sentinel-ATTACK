## Execution (T1059.001)  

Hands-on security investigation and multi-layer telemetry analysis of MITRE ATT&CK T1059.001 (PowerShell). Traced attack execution across local Sysmon host logs, Microsoft Sentinel SIEM (KQL), and Microsoft Defender XDR, capturing automated defense interception of credential-dumping scripts.

Test: Invoke-AtomicTest T1059.001 -TestNumbers 1  

Atomic test name: T1059.001-1 Mimikatz. It runs Invoke-Mimikatz -DumpCreds from the PowerSploit script Invoke-Mimikatz.ps1.

## Stage B: Microsoft Sentinel & KQL Query Analysis  

Clarification about the Ingestion (SecurityEvent vs. Event): Standard SecurityEvent log routing maps into the generic Event table depending on the Azure Monitor Agent (AMA) configuration.

The Query (Event Table): Searching the generic Event table (EventID == 4688) tracks process executions involving PowerShell script imports.  

### The KQL Query
```kusto
Event
| where TimeGenerated >= ago(1h)
| where EventID == 4688
| where RenderedDescription has "powershell.exe"
| project TimeGenerated, Computer, RenderedDescription
| order by TimeGenerated desc

```

Correlation: The output matches the exact timestamp of the Atomic Red Team execution, proving successful end-to-end log forwarding from the local host to the Microsoft Sentinel cloud workspace.
